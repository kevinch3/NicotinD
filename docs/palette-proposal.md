# Palette proposal — every preset, with its contrast table (2026-11)

The token proposal of the visual refresh (#1662, sub-issue #1683). It turns the owner's answers to
the theme audit ([theme-audit.md](theme-audit.md), Q1–Q5, answered 2026-11-09) into a token set for
**all seven presets**, maps the old names onto it, and measures every pair against WCAG AA. It is a
proposal: **no token changes here**. #1684 lands it, #1685 migrates the holdouts, #1686 and #1687
restyle components and surfaces.

Already in `styles.css` from #1818 (slice a of #1684): `--theme-accent-2`/`-2-text`/`on-accent-2`
(Q1 A) on every preset, `--theme-surface-1` as an alias of `--theme-surface`, and the Forest and
Warm Paper fixes from #1796. This proposal builds on those values and leaves them unchanged.

## The token set

| Token | Job | Decision |
| --- | --- | --- |
| `--theme-bg` | the page | Q5 A: a slight indigo tint on Midnight and Daylight only |
| `--theme-surface-1` (old `--theme-surface`, aliased) | cards, tab bar, mini player, header | |
| `--theme-surface-2` | controls, inputs, chips | |
| `--theme-surface-3` **new** | hover and pressed on a raised surface; no accent text on it | Q4 A: tonal steps first |
| `--theme-border` | separators and control outlines | Q4 A: no longer equal to `surface-2`, so a control's border shows |
| `--theme-text-primary/-secondary/-muted` | three text levels | move with the ramp, to clear 4.5:1 up to `surface-3` |
| `--theme-accent`, `-accent-text`, `-on-accent` | "press me", "you are here" | unchanged except Daylight (separated from Midnight) |
| `--theme-accent-2` family | "now playing / live" | Q1 A, shipped in #1818 |
| `--theme-hue-1…8` **new** | coverless placeholders and genre tiles only | Q2 A: one fixed set, picked by a stable hash |
| `--theme-cover-wash` **new, runtime** | low-alpha wash from the artwork | Q3 **B**: Now Playing, mini player, album and artist headers |
| `--theme-elevation-*` | shadows | Q4 A: only on what floats (tiles, menus, sheets, mini player) |
| status pairs | progress / done / warn / error | unchanged |

**`--theme-hue-1…8`.** These are the end colours of the eight vibe gradients in
`lib/vibe-presets.ts`: amber, sky, fuchsia, red, violet, yellow, orange and emerald. Each is mixed
into `surface-1` the way `.chip-tone-*` already mixes source tones
(`color-mix(in srgb, <hue> 16%, var(--theme-surface))` for the fill, 60% into `text-primary` for a
glyph, `styles.css` `.chip-tone-network`). That way they follow each preset's lightness, with no
per-preset hex table. On E-Ink every hue resolves to `surface-2` (a new rule: the chip tones have no
E-Ink override today). The same eight tint the genre and tag chips, which is the
"richer tag palette" this issue asked for: one set, not a second one.

**`--theme-cover-wash`.** It is set at runtime from `loadCoverPalette` (`lib/cover-colors.ts`, which
already runs for karaoke), as `color-mix(in oklab, <dominant> 18%, transparent)` over the surface. The
alpha is clamped so that `text-primary` and `text-secondary` keep 4.5:1 over the composited
colour. If the clamp cannot hold, the wash is dropped. It is `none` on E-Ink and under
`prefers-contrast: more`. Q3 B adds the album and artist headers to the audit's draft, so the
artwork can tint those two pages too.

**Radius rule (Q4 A).** `rounded-lg` for controls, `rounded-xl` for cards, `rounded-full` for pills.
No radius changes. #1686 applies the rule where a call site breaks it.

## Method

Midnight and Daylight take the audit's draft values verbatim (Q5 A tint included). For the other
five presets, one rule:

- `surface-3` = `surface-2` mixed 7% toward `text-primary` (8% on the light presets).
- `border` = `surface-2` mixed 14% toward `text-primary` (16% on the light presets).
- Each text level moves toward `text-primary` by the smallest 1% step that reads at least 4.6:1 on
  **every** level (`bg` to `surface-3`). `accent-text` gets the same treatment on `surface-2`.
- **Warm Paper:** its `bg → surface` step measured 1.03. The card is raised to white instead of
  darkening the page, because a darker page drops the amber fill to 2.93:1. #1818 had just lifted
  that fill to 3.15.
- **E-Ink:** no change. Its rules stay as they are, and `surface-3` equals `surface-2`.

The tables below are generated by
[`measurements/palette-2026-11/palette.py`](measurements/palette-2026-11/palette.py) from `styles.css`
as of master `741c5493`. Re-run it after any token change:
`python3 -I docs/measurements/palette-2026-11/palette.py packages/web/src/styles.css`.

## What #1684 asserts

`theme.spec.ts`'s contrast table (from #1818) gains the new pairs, with the same targets: secondary
and muted text on `surface-3`, `border` against `surface-2` (a rise, at least 1.3), and a
monotonic `bg → surface-1 → surface-2 → surface-3` on every preset except E-Ink. The table above is
what that spec should read once #1684 lands, so a mismatch means the CSS drifted from this proposal.
